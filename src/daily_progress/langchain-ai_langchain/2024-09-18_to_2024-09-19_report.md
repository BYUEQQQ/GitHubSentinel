# LangChain 项目进展

## 时间周期：2024-09-18至2024-09-19

## 新增功能
- 增加了对 `BaseIndex` 抽象的支持
- 为集成测试添加了速率限制器
- 在 `vectorstores` 模块中，将 `texts` 参数更新为 `List[str]` 类型，取代之前的 `Iterable[str]`。

## 主要改进
- 重新合并了与 pydantic v3 的变更，增强了项目对新版本的兼容性。
- 针对回调系统进行重新规划，以优化框架设计。
- 在标准测试中增加了简单的超时设置，提升测试的稳定性。
- 为 `langchain-openai` 模块新增最大 tokens 的功能请求，以更好地支持全 LLM 上下文的使用。

## 修复问题
- 解决了 `OpenAI Base Chat Model` 在处理嵌套字典时的错误。
- 修复了 `AzureOpenAI` 对象缺少 `bind_tools` 属性的问题。
- 修复了 `GoogleGenerativeAIEmbeddings` 的 `embed_documents` 方法返回重复类型列表的问题。
- 修正了 XML 文档加载器中的拼写错误。
- 清理了 `@pre_init` 的默认查找问题，提升社区贡献的代码质量。
- 针对多个宽范围问题进行了重要的修复，包括属性错误和类型错误，增强了整体稳定性。
