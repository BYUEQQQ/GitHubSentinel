# LangChain 项目进展

## 时间周期：2024-11-03至2024-11-05

## 新增功能
- 发布了标准测试版本0.3.0 (#27900)。
- 添加对SAP HANA Vector hnsw索引创建的支持 (#27357)。
- 设置了`PowerBIToolkit`的默认`output_token_limit`值以修复验证错误 (#26308)。

## 主要改进
- 更新了Vectara集成 (#27869)。
- 调整了litellm客户端的`api_key`参数以根据提供者的API密钥进行设置 (#27851)。
- 提升了langsmith SDK版本并运行了CI (#27813)。

## 修复问题
- 修复了文档加载器CSV示例笔记本中的未定义“data”变量问题 (#27872)。
- 修复了GraphVectorStoreRetriever中的一个BUG (#27846)。
- 解决了与ChromaDB兼容的OllamaEmbeddings抛出“invalid input type”错误的问题 (#27831)。
- 修复了多个文档中的链接和拼写错误，包括对配套文档中VectorStore资料的更新 (#27844, #27843, #27842, #27841, #27838)。
- 修复了一些基础设施标签计算和输出的问题 (#27892, #27891, #27890, #27836)。 

此次进展集中于新功能的发布、主要组件的改进，以及多个文档和代码中的BUG修复，提高了整体项目的稳定性和可用性。
